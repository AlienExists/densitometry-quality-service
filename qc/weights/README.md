Сюда кладутся веса моделей: `spine.pt`, `femur.pt`, `region.pt`.

В git они не попадают (см. `.gitignore`): каждый файл около 45 МБ, а каждое обновление весов раздувало бы историю репозитория.
Веса прикладываются к релизу на GitHub (Releases → Assets); после скачивания положите три файла в эту папку.

Без весов бэкенд можно запустить в режиме заглушки: `QC_DUMMY=1`.
